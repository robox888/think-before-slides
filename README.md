# 想清楚再做 PPT（think-before-slides）｜汇报逻辑与逐页大纲助手

**慢想快做——动手画页面前，先把汇报目的、论据和逐页大纲磨扎实。**

> **📍 它在哪一步帮你？**
> `零散想法 / 原始数据` ➔ **【本工具：理清思路，产出 Markdown 逐页大纲 + 评审意见 + 讲稿】** ➔ `再交给设计师或 PPT 生成工具做排版`
> *（只定“每页写什么、顺序怎么排、论据撑不撑得住”，不直接生成排版后的 PPTX 文件）*

可以从一句模糊想法、一堆材料或一份现成稿开始；每一步都写进本地 Markdown 文件，隔天或换对话都能接着做。

## 开箱即用（一句话安装并启动）

**会用命令行**：把仓库克隆到工作区的 skills 目录（以 `.agents/skills/` 为例；Claude Code 用户可放到 `~/.claude/skills/`）：

```bash
git clone https://github.com/robox888/think-before-slides.git .agents/skills/think-before-slides
```

**不用命令行**：在本页点 **Code → Download ZIP**，下载到电脑的「下载（Downloads）」文件夹，然后把下面这句话发给你的 AI 助手（Mac / Windows 通用，不用手动解压，也不用改路径）：

```text
在系统下载目录（Mac 为 ~/Downloads，Windows 为 %USERPROFILE%\Downloads）找到 think-before-slides-main.zip，解压到当前工作区的 .agents/skills/think-before-slides/，按里面的 SKILL.md 启动，先给我看 5 个常见场景。
```

装好以后，下次开新对话只要说一句：

```text
$think-before-slides 我想准备一份关于【填你的主题】的汇报大纲
```

（不装进 `.agents/skills/` 也能用：解压后直接对助手说「读一下 `think-before-slides/SKILL.md`，带我准备汇报大纲」即可。）

## 五个典型场景

不知道怎么开口时，直接挑最接近你现状的一句说就行（在对话里说 `/帮助` 也能随时调出）：

| 你的现状 | 直接这样开口 |
|---|---|
| **1. 只有题目，不知道讲什么** | 「下周要给运营总监讲客服积压，我还没想好讲什么。」 |
| **2. 材料一堆，不知道哪些能用** | 「材料在这个文件夹，帮我看看能说明什么。」 |
| **3. 知道要讲什么，想排顺序写成稿** | 「先说结论再讲依据，写成三页。」 |
| **4. 已经有稿，想挑毛病再改** | 「先别改，看看这份稿有没有硬伤。」 |
| **5. 要上台讲，或交给别人接手** | 「上台怎么说？」「整理一下，交给同事做页面。」 |

每个场景的完整对话示例、产出文件和多轮迭代方式，见 **[使用场景与工具一览](references/help.md)**。

## 每个工具都能反复用

常用口令：`/准备` `/素材` `/叙事` `/写作` `/评审` `/改稿` `/讲稿` `/交接` `/进度` `/继续` `/帮助`。不记口令、直接说人话效果一样。

所有步骤都没有固定顺序，随时可以回头再来一次：
- **补了新数据** → 再用 `/素材`，接着往后编号（M03、M04），如果推翻了原判断会自动标出受影响的页面。
- **想换个讲法** → 再用 `/叙事`，新路线追加在同文件里，旧路线保留，随时能换回来。
- **改完想再审一轮** → 再用 `/评审`，新一轮意见写在最前面，并逐条核对上一轮的问题解决了没有。
- **局部调整或重写** → 再用 `/写作` 或 `/改稿`，小改只动指定页，整份重写前自动把旧稿存进 `归档/`。

## 汇报大纲文件存在哪

每个汇报议题单独建一个文件夹（默认在工作区的 `projects/创建日期-议题名称/`，如 `projects/20261023-客服积压分析/`；若工作区已有项目目录规范则优先沿用）：

```text
20261023-客服积压分析/
  当前进度.md               记录做到哪、还缺什么、下次从哪接
  00-准备/本次汇报.md        谁讲给谁听、希望对方怎么回应
  01-盘素材/素材与判断.md    材料编号、能说明什么、还缺什么
  02-叙事/叙事选择.md        候选路线与选定顺序
  03-写作/逐页大纲.md        每页标题、观点与支撑依据（按需附 讲稿.md）
  04-评审/评审意见.md        按轮次记录的挑刺意见与 修改说明.md
  05-交接/交接说明.md        交给同事或下一个 AI 的上下文清单
  skills/INDEX.md           借用外部 skill 时才生成
```

用到哪一步才建哪个文件，不预建空目录。隔天继续时，把议题文件夹路径发给助手，说「接着上次」即可。

## 借用你自己的 skill

如果你有顺手的写作润色或审稿 skill，可以只在这个汇报里临时挂上：

```text
把「我的写作 skill 路径」挂到这个汇报，用于改稿。只改表达，不改事实和结论。
```

可以指定「这个汇报一直用」或「只这轮用」，随时能说 `/停用`，不会污染其他汇报或全局设置。

## 配套：想清楚之后，再说人话

这个工具管"讲什么、怎么排、论据撑不撑得住"。大纲定了以后，用 AI 把它写成正文时，可以配合 **[让 AI 说人话（human-readable-chinese-writing）](https://github.com/robox888/human-readable-chinese-writing)**：7 条能逐条检查的中文写作规则，专治"太 AI 了，读不进去"。

```text
把「human-readable-chinese-writing 的路径」挂到这个汇报，用于写作和改稿。只改表达，不改事实和结论。
```
