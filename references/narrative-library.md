# 叙事方法库

按本次对象、目标、证据选择一个主线，必要时补局部方法。方法不能替代证据，也不等于固定页序。不要要求用户先学会术语。

## 主线与开场

| 方法 | 组织方式 | 适用条件与边界 |
|---|---|---|
| 结论先行／金字塔 | 主张 → 支撑理由 → 证据 → 待判断事项 | 对方需要先知道你要表达什么；核心主张须有依据，不能先下大结论再凑材料 |
| 情境—冲突—问题—回答（SCQA） | 必要背景 → 变化或矛盾 → 本次问题 → 回答 | 对方尚不理解为什么现在要谈；通常用于开场，不夸大冲突，不重复对方已知背景 |
| 行动后复盘（AAR） | 原计划 → 实际 → 差异及原因证据 → 调整建议 | 需要对齐计划和结果；原因标签不等于根因，四部分不等于固定四页 |
| 发生了什么—意味着什么—接下来怎么办 | 事实 → 对本次任务的影响 → 建议 | 已有事实，需要形成判断；不能跳过影响分析直接从数字得出行动 |
| 现状—期望—可行路径（BAB） | 现状与影响 → 希望改善什么 → 如何验证或实施 | 对方需要理解方案价值和路径；期望不能写成确定收益，路径须有依据 |
| 注意—兴趣—意愿—行动（AIDA） | 引起关注 → 说明相关性 → 展示价值 → 提出下一步 | 面向尚未关注此事的对象；对方已进入决策时压缩铺垫，不假定意愿已形成 |
| 门罗激励序列 | 注意 → 需求 → 满足 → 具体情景 → 行动 | 需要推动行动；需求、效果和可行性须有依据，不能靠渲染代替论证 |
| Duarte 演讲曲线 | 现状与期望状态交替对照 → 可行路径 | 适合需要节奏与对照的现场讲解；期望仍是期望，自行阅读时不能依赖现场感染力 |

## 局部表达与价值说明

| 方法 | 组织方式 | 适用条件与边界 |
|---|---|---|
| 情境—任务—行动—结果（STAR） | 交代具体工作背景、责任、行动与结果 | 说明一个事例或贡献；不能把团队成果全归个人，也不能把先后写成因果 |
| 观点—理由—例子—回扣（PREP） | 观点 → 理由 → 证据或事例 → 回到观点 | 组织一个局部论点或单页；回扣可以简短，不能重复观点而缺少支撑 |
| 问题—影响—解法（PAS） | 说明问题 → 交代真实影响 → 提出办法 | 对方需要理解问题为何值得解决，可用于一段或整体主线；不为紧迫感编造后果 |
| 特性—优势—利益（FAB） | 方案特性 → 有依据的优势 → 对方的具体收益 | 把技术特性转成客户能理解的价值；优势需要比较依据，收益须分已实现与预期 |
| 文案四步：承诺—画面—证据—行动 | 明确价值主张 → 描述应用情景 → 给证据 → 下一步 | 用于价值说明；不承诺证据以外的效果，不替代严谨的结果复盘 |
| 铺垫—转折—因此（ABT） | 用已有背景、关键变化和推论串起一个论点 | 适合简短解释；“因此”须有推理支持，不能只因句子通顺就加入因果 |

## 澄清、反思与论证检查

| 方法 | 用法 | 适用条件与边界 |
|---|---|---|
| 图尔敏论证 | 检查主张、证据、推理桥梁、限制及反驳 | 判断材料是否真的支持主张；用于检查论证，不是一项一页的页序模板 |
| 罗杰斯式论证 | 说明对方立场及其合理条件，再说己方立场与适用范围 | 需要化解实质分歧；不能虚构对方意见或为表面共识隐去分歧 |
| 情境—问题—影响—需求收益（SPIN） | 用相关问题识别需求和证据缺口 | 需求尚不清楚时使用；不对用户重复完整访谈，不替对方预设需求 |
| 吉布斯反思循环 | 描述 → 感受 → 评价 → 分析 → 结论 → 后续行动 | 帮助整理反思；对外汇报不必完整呈现个人思考过程，感受不能替代事实 |
| 情境—行为—影响（SBI） | 围绕具体事例说明可观察行为及影响 | 给反馈或解释局部事件；不将动机猜测写成事实，不作为整篇通用骨架 |

## 方法出处

表中的组织方式与适用边界由本 skill 作者按使用场景简写。各方法的名称、著作权及版权归原作者或原机构所有，常见出处如下：

| 方法 | 常见出处 |
|---|---|
| 结论先行／金字塔、SCQA | Barbara Minto，《The Minto Pyramid Principle》（[作者网站](https://www.barbaraminto.com/textbook)） |
| 行动后复盘（AAR） | 美国陆军（U.S. Army） |
| 发生了什么—意味着什么—接下来怎么办 | Rolfe, Freshwater & Jasper 反思模型（What? So what? Now what?） |
| 注意—兴趣—意愿—行动（AIDA） | E. St. Elmo Lewis |
| 门罗激励序列 | Alan H. Monroe |
| Duarte 演讲曲线 | Nancy Duarte，《Resonate》 |
| 铺垫—转折—因此（ABT） | Randy Olson |
| 图尔敏论证 | Stephen Toulmin，《The Uses of Argument》 |
| 罗杰斯式论证 | 源自 Carl Rogers 的沟通理论 |
| 情境—问题—影响—需求收益（SPIN） | Neil Rackham，《SPIN Selling》 |
| 吉布斯反思循环 | Graham Gibbs，《Learning by Doing》 |
| 情境—行为—影响（SBI） | Center for Creative Leadership |
| BAB、STAR、PREP、PAS、FAB、承诺—画面—证据—行动 | 文案、面试与销售领域的通用框架，无单一公认作者 |

以上为常见归属，未逐一核对原始文献；对外正式引用时请查原始来源。这些是组织与检查方法，不是项目证据，执行时不需要访问外部网站。
