# 常见问题

[返回 README](../README.md) · [使用场景](help.md)

## 一定要安装成平台 skill 吗？

不用。只要助手能读写本地文件，直接让它读 `think-before-slides/SKILL.md` 或 `think-before-slides/README.md` 就能用。安装到 `.agents/skills/` 等目录只是为了方便直接用 `$think-before-slides` 唤起。

## 输入 `/准备` 没有弹出菜单，是没装好吗？

这些口令是对话约定，不依赖平台的原生斜杠菜单。没弹出菜单照样能用；如果所用平台拦截了 `/` 开头的输入，直接说「帮我理清这次汇报的目的」效果完全一样。

## 只上传了单个文件，助手为什么说找不到其他规则？

`SKILL.md` 和 `README.md` 会按需读取 `references/` 下的分步文件。请把整个 `think-before-slides/` 文件夹解压到助手可访问的工作区，不要只上传单个 Markdown。

## 一点材料都没有，能开始吗？

能。先理清讲给谁听、希望对方怎么回应（见 [场景 1](help.md#场景-1只有题目不知道讲什么)），或者先搭一个待验证的骨架。还没拿到数据的部分会标为“待核实”，不用为了走流程去编数据。

## 已经有现成稿了，还要从“准备”走起吗？

不用，直接把稿子发给助手让它评审或改指定页（见 [场景 4](help.md#场景-4已经有稿想挑毛病再改)）。助手会自己从现稿里提取背景，只补问最影响判断的一两个问题。

## 同一个工具能反复用几次？

不限次数，也没有固定顺序。每次再用都会在原文件上增量更新：`/素材` 接着往后编号，`/叙事` 追加新路线并保留旧路线，`/评审` 按轮次累加并核对上轮问题，`/讲稿` 跟着最新页面同步。详情见 [工具一览](help.md#工具一览)。

## 助手问得太多怎么办？

直接说「先做能做的，每次只问最关键的一个问题」。暂时答不上来的问题，可以说「你先给个建议」或「先跳过」，助手会标为暂定并继续往下推进。

## 助手说保存了，但我没找到文件？

让它发出实际写入的文件路径，并读回刚写的内容确认。只在聊天框里输出文字不算落盘；如果当前环境没有写文件权限，助手会直接说明并把整理好的 Markdown 发给你复制。

## 换个对话还能接着做吗？

能。在新对话里加载本 skill，把汇报议题文件夹的路径发给助手，说「接着上次做」。助手会先读里面的 `当前进度.md`，已经定过的事不会重问。

## 汇报多了，目录谁来管？

助手自动维护。如果工作区已有项目总表就沿用；没有时，助手会在工作区的 `projects/INDEX.md` 里登记每个汇报议题的位置。平时改稿不会频繁改动总表。

## 借用的外部 skill 打不开了怎么办？

助手会指出具体缺哪个文件。你可以给新路径，也可以说「先不用它」，继续用本 skill 自带的方法完成。

## 会自动生成 PPTX 或发到飞书吗？

不会自动执行。本 skill 产出的是 Markdown 格式的逐页内容和讲稿。需要生成幻灯片或上传飞书时，单独告诉助手用哪个制作工具、发到哪里。

## 数字和结论能保证绝对准确吗？

助手会用工具复算数字、核对统计口径，并把“已有证据支持的结论”和“待验证的猜测”分开写；但业务事实本身和最终决策，仍需要你来把关。
