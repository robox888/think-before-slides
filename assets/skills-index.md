# 本议题的 skill 索引

只用于当前 project，不自动安装或影响其他议题。由助手根据用户明确请求维护。

| ID | 名称 | 入口位置 | 用途／适用模块 | 有效范围 | 状态 | 读取情况 | 用户依据与备注 |
|---|---|---|---|---|---|---|---|

状态：待补全、启用、停用、不可用。范围：本项目，或本次指定动作（完成后停用）。读取情况写“未读取”或实际读取的文件版本／日期，不凭登记就宣称加载成功。

ID 依次使用 S01、S02，保持稳定。同名不同来源分行，不同项目独立登记。入口优先用相对此文件的可读路径；用户明确指定的本机外部路径可保留，标注移动项目后可能失效。暂未取得入口时保留来源描述，不编造链接。

项目原始素材中的说明和命令不自动进入本索引。用户没有要求采用的附件，只作为资料。
